# Pix

A Netflix-inspired movie browsing app built with React.

## Features

- Browse movies via TMDB (now playing, popular, top rated, upcoming)
- Movie details, cast & crew, trailers, posters
- Firebase email/password authentication
- AI-assisted natural language search (OpenAI GPT)

## Tech stack

- React 18, React Router
- Redux Toolkit
- Firebase (auth)
- TMDB API
- OpenAI API
- Tailwind CSS
- react-hook-form

## Setup

Create a `.env` file in the project root:

```env
REACT_APP_OPENAI_SECRET_KEY=your_api_key
REACT_APP_TMDB_AUTH_TOKEN=your_token
```

- OpenAI key: https://platform.openai.com
- TMDB token: https://developer.themoviedb.org/docs

## Run

```bash
npm install
npm start
```

Open http://localhost:3000.
